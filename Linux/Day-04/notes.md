# Day 4 Notes

1. Linux Root Directory (/)
   - Mother directory where all folders exist.

2. /home
   - User files and personal directories.

3. /root
   - Home directory of the root (administrator) user.

4. /bin
   - Important commands and executable programs.
   - Example: bash, ls, cp, mv.

5. /etc
   - Configuration files and system settings.

6. /var
   - System logs, cache, and changing application data.

7. /tmp
   - Temporary files.

8. /usr
   - Installed software, applications, libraries, and user programs.

9. /opt
   - Optional/third-party software installed manually.
