# Day 6 Notes

1. File Ownership
   - Every file and directory has an owner.

2. chown
   - Used to change the ownership of a file or directory.

   Example:
   chown john report.txt

3. Package Management
   - Linux uses package managers to install, update, and remove software.

4. apt
   - Package manager used in Ubuntu/Debian systems.

5. Installing Software

   Example:
   sudo apt install git

6. apt update
   - Refreshes the package list.
   - Checks for available updates.

   Example:
   sudo apt update

7. apt upgrade
   - Installs available software updates.

   Example:
   sudo apt upgrade

8. Processes
   - A running program is called a process.

   Examples:
   Chrome
   VS Code
   Docker
   Jenkins
   Python Script

9. Process ID (PID)
   - Unique identifier assigned to every process.

10. ps
    - Displays running processes.
    - Provides a snapshot of currently running processes.

    Example:
    ps

11. top
    - Real-time process monitoring tool.
    - Similar to Windows Task Manager.

    Example:
    top

12. kill
    - Terminates a running process using its PID.

    Example:
    kill 5678

13. Linux Process Management
    - Monitor processes using ps and top.
    - Stop processes using kill.
