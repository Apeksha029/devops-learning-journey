
# Day 7 Notes

1. Services
   - Programs running in the background.
   - Examples: SSH, Docker, Jenkins, Apache.

2. systemctl
   - Used to manage services.

3. Check Service Status

   Example:
   systemctl status ssh

4. Start a Service

   Example:
   sudo systemctl start ssh

5. Stop a Service

   Example:
   sudo systemctl stop ssh

6. Restart a Service

   Example:
   sudo systemctl restart ssh

7. Process vs Service

   Process
   - Any running program.

   Service
   - Background process managed by the system.

8. ping
   - Checks if a machine is reachable.

   Example:
   ping google.com

9. curl
   - Sends an HTTP request and displays the response.

   Example:
   curl https://google.com

10. SSH (Secure Shell)
    - Used to securely connect to another computer/server.

    Example:
    ssh ubuntu@192.168.1.10

11. Remote Access
    - SSH allows remote login and management of servers.
