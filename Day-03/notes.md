# Linux Day 3 - Essential Linux Commands

1. pwd (Print Working Directory)

2. ls (List)

3. cd (Change Directory)

4. mkdir (Make Directory)

5. touch (create empty file)

6. clear (clear terminal screen without deleting any files or folders)

7. echo (just print whatever is said)

8. cat (read the content inside the files)

9. cp (Copy)

10. mv (Move / Rename)
