# What Happens When I Open google.com?

1. Browser receives google.com
2. Browser asks DNS for IP address
3. DNS returns IP address
4. Browser connects to server using HTTPS
5. Request reaches Google server
6. Server sends HTML, CSS and JavaScript
7. Browser renders webpage
